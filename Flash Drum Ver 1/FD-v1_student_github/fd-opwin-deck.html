Definition

Four things make an operating window

Operability: enough capacity and flexibility to reach a range of conditions safely, reliably and profitably. The operating window is every steady state with all set points held and no bound crossed.

Part 3 · summary

What part 3 settled

  • Type I: a small sloping island, not a rectangle.
  • Type II: a set-point band about 12 °C wide.
  • Type III: feed butane narrows the window most.
  • Monte Carlo: centred set points raise the fraction inside.
