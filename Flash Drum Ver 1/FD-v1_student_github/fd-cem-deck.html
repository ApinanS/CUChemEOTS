Notes 3, 4 and 8 of the matrix

Four words carry the timing

Part 1 read the cells; now: when each one acts.

Delay

The cause must persist for the set time before the logic acts.

Latch

The trip holds after the cause clears.

First-out

Only the cause that tripped I-1 is flagged.

Reset · permissive

Restart is allowed only when no cause remains.

Part 2 · summary

What part 2 settled

  • Delay, logic scan and valve stroke add up to the response.
  • Process alarms lead; one trip row takes the first-out.
  • I-1 and I-2 latch until reset with no cause present.
  • Put the feed and hot-oil loops in MAN before reset.

Key Takeaways

1

Read each row as one sentence: cause, delay, effects.

2

Build each trip row from the safe state in the SRS.

3

Check delays against the process safety time.

4

Keep trip sensors separate from the control loops.

5

Fire every trip row on the model and read the first-out.
