Definitions

The logic is proven twice, then the loops

Before any valve moves on process, the SIS must do exactly what the C&E says.

FAT · at the vendor

I/O check, every C&E row, graphics, alarms.

SAT · on site

Same tests after installation in the control building.

Loop check

Each signal end to end: 0, 25, 100 %.

Stroke test

XV-408, XV-409, XV-418 close in ≤ 2 s (SRS).

Interactive · run a C&E row on a copy of the model

Cause in, valve positions out

All 27 C&E rows pass: I-1 shuts feed and hot oil, ESD also the bottoms, and a latched trip refuses an early reset.

Mechanical completion

Punch items are sorted by what they block

With the logic proven, construction walks the plant down and lists what is left.

Category A

Clear before pre-commissioning or hydrocarbons: safety, pressure, SIS, relief.

Category B

Clear before handover: works, but incomplete.

Category C

After handover: cosmetic, documents, spares.

MC certificate

Built to drawings, pressure tested, no A open.
