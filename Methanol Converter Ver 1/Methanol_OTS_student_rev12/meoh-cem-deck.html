Notes 4, 7 and 8 of the matrix

Four words carry the timing

Part 1 read the cells; now: when each one acts.

Delay

A trip cause must persist 5 s before SIS-201 acts.

Latch

The trip holds after the cause clears, until reset.

First-out

Only the cause that tripped SIS-201 is flagged.

Suppression

Process alarms go quiet once the make-up or C-201 stops.

Part 2 · summary

What part 2 settled

  • Sensor, 5 s delay, scan and stroke add up to 7.75 s.

Part 3 · Reset and restart

When may the operator reset and reopen the make-up?

Part 3 · the plan

Two gates before the make-up returns

  1. The reset ruleblocked while a blocking cause is present
  2. The FSLL-201 exceptionit does not block the reset
  3. Six start permissivesPERM-1 to PERM-6 must all be met
  4. Restart replayshow long each gate held on the model

SIS-RST row and note 5

Gate 1: reset; gate 2: the permissives

A latched trip stays latched; the sequence rows decide when it may clear.

Reset blocked

While TSHH-2xx, LSHH-204 or PSHH-203 is still present.

FSLL-201 does not block

It is armed only while XV-202 is open.

After the reset

SIS-201 is ready; XV-202 is still shut.

Opening XV-202

Only when PERM-1 to PERM-6 are all met.

Part 3 · summary

What part 3 settled

  • Reset is blocked while TSHH, LSHH or PSHH is present.
  • FSLL-201 does not block: reset at once after a C-201 trip.
  • XV-202 opens only with PERM-1 to PERM-6 all met.
  • After a TSHH trip, the 280 °C permissive sets the wait.

Key Takeaways

1

Read each row as one sentence: cause, setting, delay, effects.

2

Build each trip row from the safe state in the SRS.

3

Read the first-out, not the alarm list, to find the cause.

4

Reset only when the cause has cleared; then work through the permissives.

5

Fire every trip row on the model before the matrix is issued.
